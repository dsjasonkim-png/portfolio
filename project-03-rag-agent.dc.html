쇼핑 AI Agent / RAG 기반 상품 탐색·추천 PoC

프로젝트 책임자 — 기획·설계, 기술검증 및 개발
  • 기존 검색·필터 UI는 고객이 스스로 스펙 용어를 알고 조건을 입력해야만 원하는 상품을 찾을 수 있어, "이런 상황에 뭐가 좋을지" 묻는 자연스러운 쇼핑 대화를 지원하지 못함
  • 고객이 자연어로 질의하면 제품군·예산·사용 맥락·필수 조건을 해석하고, 상품 지식을 검색·재정렬해 추천 근거와 함께 응답을 생성하는 대화형 추천 구조를 검증한 PoC

아키텍처

개발 환경
RTX4090 · 64GB RAM (개발용 PC) · Gemma3-4B(fp16) · vLLM · FastAPI · LangGraph(오케스트레이션) · LangChain(RAG 파이프라인) · FAISS · GraphRAG(Neo4j) · Gradio(챗봇 UI) · 임베딩 dragonkue/BGE-m3-ko

1. AI Agent 구조 검토 및 프로토타입 설계

  • LangChain·LangGraph 기반으로 고객 질의에서 제품군, 예산, 사용 맥락, 핵심 조건을 추출하는 질의 해석 구조 설계
  • 추천 Agent, 지식 Agent, CS Agent 등 멀티 Agent 기반 쇼핑 지원 구조 검토 및 상품 데이터 파이프라인 설계
LangChainLangGraphMulti-Agent 설계

2. Slot Filling 기반 추천 그래프

  • "냉장고 추천해줘" 같은 첫 질의에 무작정 추천하지 않고, 가족 규모(용량)·원하는 형태(양문형·4도어·빌트인)·예산 범위·특수 기능 필요 여부를 상담으로 수집(Slot Filling)
  • 이후 그래프는 첫 추천 → 추가 질문(스펙·비교) → 같은 품목 내 다른 상품 추천 → 다른 품목 추천의 4가지 분기로 대화 진행
LangGraph State Machine

3. 품목→상품 2단계 계층 검색

  • 품목별로 별도의 벡터 DB를 구성해 유사 품목 간 검색 혼선(예: 냉장고 vs 김치냉장고) 감소
  • 질문 대상 품목을 먼저 Retrieve한 뒤 그 안에서 상품을 다시 Retrieve하는 2단계 구조로 정확도 향상
  • 상품 스펙과 OCR-LLM 기반 FABEC 판매논리를 함께 임베딩(dragonkue/BGE-m3-ko)해 Semantic Search·Reranking에 활용
RAGVector DB / FAISSSemantic SearchReranking

4. 개인화 컨텍스트 연계

  • CDP에 통합된 고객 세그먼트·재구매주기 데이터를 추천 Agent의 개인화 컨텍스트로 연계
  • 고객별 관심 상품군과 재구매 예상 시점을 AI 추천 후보군 생성에 반영
CDP 연계Personalization

온·오프라인 통합 개인화 추천 & 고객 데이터 자산화

  • 오프라인 매장 상담 데이터와 온라인 행동 데이터가 분리되어 고객 한 명의 관심사·재구매 주기를 통합 파악하기 어려운 상태
  • 과제: 온·오프라인 전 채널에서 활용 가능한 통합 고객 프로파일 구축

아키텍처

1. 고객 세그먼트 기반 추천 로직 개발

  • 고객 생애주기·구매성향 지표를 조합해 729개 고객 세그먼트 구성
  • 고객별 관심 상품군·재구매주기를 반영한 추천 로직 개발
  • 오프라인 매장 상담용 태블릿에 고객별 추천 상품군·상품 리스트 제공
Python SQL Recommendation Customer Segmentation

2. 구매가망모형(Lift 기반 타겟팅)

  • GA 행동 데이터·과거 구매 이력·고객 세그먼트를 변수로 활용한 머신러닝 기반 구매가망모형 개발
  • Lift 지표 기준 마케팅 타겟 고객군 선정
Machine Learning Lift Analysis scikit-learn

3. CDP 통합 및 고객 프로파일 구조화

  • 고객 세그먼트·추천 상품군·재구매주기 데이터를 CDP로 이관, 온·오프라인 통합 고객 프로파일로 구성
  • CDP 고객 Feature를 쇼핑 AI Agent의 개인화 컨텍스트·CRM 활용 데이터와 연계하는 구조 설계
CDP Customer Profile Integration Data Architecture

2. OCR·LLM 정제 파이프라인

  • easyOCR로 텍스트 추출 (tesseract 대비 성능 우세 확인)

3. FAB / FABEC 판매논리 자동생성

단순 기술 설명(Feature)을 고객 중심 가치로 전환하는 FAB 구조 문구를 자동생성했습니다.

Feature — LG 4도어 냉장고, 870L 대용량
Advantage — 넉넉한 용량 덕분에 대가족도 충분히 사용
Benefit — 주말에 대량으로 장을 봐도 여유롭게 보관 가능
  • Experience·Context를 더한 FABEC 구조로 확장해 AI Agent 시맨틱 검색 성능 향상 — 예) {'Feature':'NEW 유산균김치+ 기능','Advantage':'유산균 함량 57배 증가','Benefit':'김치 맛과 품질 유지','Experience':'아삭하고 깊은 맛 경험','Context':'오래 보관해도 신선함'}
  • 지점 판매 상담용(FAB 전문)과 하이마트몰 온라인용(축약 키워드) 두 가지 버전으로 생성
Prompt EngineeringFABEC Framework

4. Taxonomy 설계 — 하향식 + 상향식 병행

  • 하향식 — 상품 카테고리는 네이버·쿠팡 등 업계 표준 체계를 레퍼런스로 LLM 클러스터링 후 MD 검증을 거쳐 확정
  • 상향식(Taxonomy Induction) — 참고 표준이 없는 상품 속성은 OCR 원문을 LLM으로 그룹핑해 카테고리 생성·매핑
Taxonomy DesignLLM Clustering

5. 다단계 검증 Agent 및 Feedback Loop

  • OCR 원문 대조, 상품 단위 정합성 검증, Web Search API grounding을 결합한 다단계 검증 Agent 설계
  • 추출 결과 검수·오류 확인·재처리를 위한 운영 대시보드 개발
  • Feedback Loop — 검증 Agent가 잡아낸 오류를 품목군별로 유형화(특정 카테고리 반복 OCR 오탈자, 특정 속성 반복 LLM 환각 등)
  • 해당 품목군의 Prompt·Rule 개선에 반영하는 순환 구조 구축, 오류 재발 품목군 우선순위로 정제 프롬프트 반복 튜닝
  • 운영 개시 이후 검증 통과율이 지속적으로 개선되는 구조로 설계
AI AgentWeb Search API GroundingDashboard

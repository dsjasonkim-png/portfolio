Study 1 · OCR-LLM 기반 판매논리 자동 생성

2개 모듈·4개 서브모듈로 구성된 자동화 파이프라인.

텍스트 추출 모듈

  • 전처리 — Histogram Equalization·CLAHE로 명암 대비를 높여 텍스트 가독성 개선. CLAHE 적용 OCR이 원본보다 낮은 평균 CER을 보임
  • 검출·분할 — CRAFT로 텍스트 위치 검출 후, 글자가 잘리지 않는 좌표에서 이미지 분할, 분할 이미지별 OCR 실행 후 원래 순서로 병합. 핵심은 단순 일정 크기 분할이 아니라 텍스트 검출 위치 기준의 분할
  • OCR — EasyOCR(검출 CRAFT, 인식 CRNN), CPU Only 환경에서 실험

LCORE — LLM 기반 문맥적 OCR 정제

LCORE(LLM-based Contextual OCR Refinement)는 OCR 결과를 상품의 품목·상품명·문맥 기준으로 정제하는 단계입니다.

  • 입력: OCR 텍스트·상품 품목·상품명
  • 맞춤법 수정, 문맥 불일치 문장 수정·삭제, 상품 문맥 기반 오류 복원
  • 제공된 정보 범위를 벗어난 새 사실 생성은 방지

설득형 지식베이스 — FABEC

Study 2는 Study 1의 FAB를 확장한 FABEC(Feature·Advantage·Benefit·Experience·Context) 구조를 사용합니다. Experience(고객 경험)·Context(사용 맥락)가 Study 2에서 새로 확장되었습니다.

Study 2 · 설득형 지식 기반 상품 추천 AI 에이전트

사용자 인터페이스 → 질의 해석기(의도·상황·맥락) → 시맨틱 검색(설득형 지식 검색) → 재정렬 모듈(후보 우선순위) → 응답 생성기(설명형 추천 응답) 순서로 이어지며, 대화 메모리가 이전 대화·사용자 맥락을 유지합니다.

실험 설계 — Baseline vs Proposed

동일한 검색 파이프라인에서 문서 표현 방식만 바꿔 비교 — Baseline(상품 속성만) vs Proposed(상품 속성 + FABEC·구매동기). 목적은 정답 상품을 찾는지가 아니라 사용자 의도에 더 적합한 상품을 상위에 배치하는지 검증.

실험 1 — 자체 구축 데이터

  • 롯데하이마트 노트북 상품 49개의 속성·상세페이지·FABEC 문서로 검색 데이터셋 구성
  • 6개 SONCAS×3개 질의유형×3개 질문구조로 후보 질문 148개 생성, gemma4:e2b·llama3.1:8b 두 모델이 Fluency·Clarity·Relevance·Consistency·Answerability 기준으로 독립 검토해 최종 질문 54개 확정
  • Schema 정규화(주요 동기·필수 제약·선호)를 거쳐 관련성 0~2점 qrels 생성, hard disagreement(2점 vs 0점) 197개 제외
  • TREC Pooling 기반 후보 881개 중 최종 qrels 684개 구축

실험 2 — Amazon ESCI 외부 검증

  • 공개 데이터셋(ESCI US test small)으로 일반화 가능성 검증 — 질의–상품 쌍 181,701개, 질의 8,956개, 상품 164,900개
  • 사람이 부여한 기존 relevance label(Exact=2·Substitute=1·Complement/Irrelevant=0)을 그대로 사용, LLM은 정답 라벨·질의 생성에 미관여

연구의 통합적 해석과 기여

Study 1이 상품 정보를 소비자 관점의 설명 지식으로 변환하는 지식 생성 계층이라면, Study 2는 이 지식을 검색·추천·응답에 활용하는 서비스 계층입니다.

  1. OCR 정확도 개선에 그치지 않고 판매논리 생성까지 연결
  2. 단순 스펙이 아니라 특징–장점–혜택–경험–맥락을 포함하는 설득형 지식 표현
  3. 판매자의 상품정보를 자연어 질의 대응용 검색 문서로 확장
  4. 자체 데이터와 사람 라벨 기반 공개 데이터(ESCI) 모두에서 검색 성능 검증
  5. 질의 해석·대화 메모리·재정렬·설명 응답을 포함한 AI 에이전트 구조 제안

연구의 한계와 향후 확장

  • 상세페이지 이미지·OCR 텍스트 중심이라, 텍스트 위치·시각적 레이아웃 정보는 아직 활용하지 못함
  • 고객 리뷰데이터를 반영하면 판매자 정보와 고객 인식의 일치성, 고객 경험·맥락을 더 구체화 가능
  • 구매동기 자극 여부·다층적 생성은 정량화하고 전문가 검토로 실무성을 확인했으나, 판매논리의 질·깊이에 대한 직접적 정량평가는 향후 과제

# 김홍대 — 데이터/AI 포트폴리오

## 소개

리테일·커머스 도메인에서 수요예측, 가격·재고 최적화, 고객 세그멘테이션·개인화 추천 등 다양한 비즈니스 문제를 통계·머신러닝 모델링으로 풀어왔습니다. 최근에는 AI가 상품을 이해하고 추천하게 만드는 문제를 가장 깊게 파고 있습니다 — 상품 지식을 구조화하는 Taxonomy 설계, LLM·RAG 기반 AI Agent 개발, Prompt Engineering을 실무와 박사 연구 양쪽에서 수행하며 GenAI 기반 AI 서비스를 기획부터 구현까지 리드해 왔습니다.

문제 정의부터 모델링, 서비스 적용, 성과 검증까지 프로젝트 전 과정을 리드했고, 클라이언트 요청으로 PM/PL을 맡아 팀을 이끈 경험도 갖추고 있습니다.

## 핵심 역량

- 상품·고객 지식을 구조화하는 Taxonomy 설계 및 LLM Prompt Engineering Input 체계화
- LLM·RAG·Vector DB 기반 AI Agent 서비스 기획·설계·구현
- 비즈니스 이슈 정의 → 데이터/AI 과제 구체화 → 모델 개발 → 서비스 적용 → 성과 검증까지 전 과정 리드
- 리테일 상품·판매·고객 데이터 기반 수요예측, 가격·재고 최적화, 고객 세그멘테이션·개인화 추천 등 다영역 모델링
- 클라이언트·현업과의 커뮤니케이션 기반 PM/PL 수행 및 팀 리드 경험
